# EcoҚуат — «Электр энергиясын есептеу» (задание №41)

Приложение для ПК и телефона. Считает оплату за электроэнергию по тарифам регионов Казахстана,
сравнивает расход с нормой семьи, учитывает технику в доме и даёт советы по экономии
(экология, углеродный след).

## Что внутри
| Папка / файл | Что это |
|---|---|
| `app/` | само приложение (HTML + CSS + JavaScript), работает без интернета |
| `app/js/data.js` | тарифы 20 регионов, нормы, техника, эко-данные |
| `app/js/app.js` | расчёты и интерфейс |
| `dist/EcoQuat.exe` | готовая программа для Windows |
| `desktop/ecoquat_desktop.py` | код окна для ПК (pywebview) |
| `build_exe.bat` | пересобрать .exe после изменений |
| `phone_wifi.py` | открыть приложение на телефоне через Wi-Fi |

## Как работает норма
В Казахстане тариф трёхуровневый. Граница 1-го уровня = **норма на 1 человека × число прописанных**.
Например, в Астане норма — 70 кВт·ч на человека (с электроплитой 90). Для семьи из 5 человек это 350 кВт·ч.
Всё, что сверх нормы, энергосбыт берёт по более дорогим 2-му и 3-му уровням.

Программа спрашивает, сколько в доме комнат, ламп и техники, и считает ожидаемый расход:
* **расход ≤ нормы** — зелёный статус, самый дешёвый тариф;
* **выше нормы, но в пределах того, что тратит техника** — жёлтое предупреждение.
  В режиме «Техника расширяет норму» тариф остаётся 1-м уровнем;
* **выше и нормы, и расхода техники** — красный статус «перерасход», уведомление и эко-советы.

В настройках можно включить режим «Строго как в квитанции»: тогда всё превышение считается по 2-му и 3-му уровням.

## Пункты задания №41
* ввод начального и конечного показаний;
* расчёт потребления;
* оплата по тарифу (3 уровня, 20 регионов);
* социальная льгота;
* долг и переплата;
* статистика за несколько месяцев;
* среднее потребление.

**Добавлено сверх задания:**
* два языка — русский и казахский (переключатель РУС / ҚАЗ вверху экрана, в настройках и на первом экране);
* анкета дома (семья, комнаты, лампы, 20 видов техники);
* норма на человека;
* эко-класс A–G;
* CO₂ и эквивалент в деревьях;
* цель экономии;
* калькулятор прибора;
* достижения;
* уведомления;
* экспорт CSV, резервная копия;
* импорт из старой программы (`electric_data.json`);
* вкладка тарифов с источниками.

## Запуск на ПК
Откройте `dist\EcoQuat.exe`, Python не нужен. Используется встроенный в Windows 10/11 движок Edge WebView2.
Данные хранятся в `%LOCALAPPDATA%\EcoQuat`.

Перенести старые данные: ⚙️ Настройки → «Импорт JSON» → выберите `Загрузки\electric_data.json`.

## Запуск на телефоне
**Быстрая проверка через Wi-Fi:** запустите `python phone_wifi.py` и откройте на телефоне адрес, который он покажет.

**Установка как приложение** (с иконкой на рабочем столе, работает без интернета):
1. Выложите папку `app` на любой бесплатный HTTPS-хостинг, например GitHub Pages или Netlify.
2. **Android:** откройте сайт в Chrome → меню ⋮ → «Установить приложение».
3. **iPhone:** откройте сайт в Safari → «Поделиться» → «На экран Домой».
4. Чтобы получить файл `.apk`: вставьте адрес сайта на pwabuilder.com → Android → Download.

## О тарифах (честно)
* **Проверены** по сайтам энергосбытов (осень 2026): Астана, Актюбинская, Костанайская, Павлодарская области.
* **Проверены цены, границы уровней типовые:** Алматы, Алматинская область, Атырауская, СКО, область Жетісу, Кызылординская (1-й уровень).
* **Ориентир:** для остальных регионов публично найден только 2-й уровень (август 2026), а 1-й и 3-й рассчитаны по типовой пропорции.

Любой тариф можно поправить по своей квитанции: вкладка «Тарифы» → «Подробнее» → «Сохранить мой тариф».
